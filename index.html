Homework #_

  • git status - команда яка відображає поточний стан
  • git branch - команда яка показує список гілок в репозиторії
  • git add . - команда яка додає всі змінені та нові файли
  • git commit -m - команда яка фіксує проіндексовані зміни і зберігає в історію версій
  • git push origin HEAD - команда яка відправляє локальні коміти з поточної активної гілки
  • git checkout -b - команда яка створює нову гілку із зазначеним ім'ям та одразу перемикається на неї
  • git branch -команда яка виводить список іменованих комітів і вказує вибрану гілку
  • git checkout main - команда яка перемикає на головну гілку проекта (main)
